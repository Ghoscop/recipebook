# RecipeBook

Sistema web de receitas desenvolvido com Angular e Spring Boot.

O projeto permite cadastrar, visualizar, buscar e excluir receitas de forma prática e moderna.

---

# Funcionalidades

## RF01 — Listagem de receitas
- Exibição em cards modernos
- Imagem da receita
- Tempo de preparo
- Quantidade de porções

## RF02 — Busca de receitas
- Busca em tempo real
- Normalização de texto
- Suporte a acentos

## RF03 — Cadastro de receitas
- Formulário completo
- Validação de campos
- Preview de imagem
- Integração com backend

## RF04 — Detalhes da receita
- Visualização completa
- Ingredientes
- Modo de preparo
- Data de cadastro

## RF05 — Exclusão de receitas
- Exclusão individual
- Exclusão múltipla
- Atualização automática da tela
